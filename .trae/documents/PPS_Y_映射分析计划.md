# PPS 与 Y 序列映射关系分析计划（修订版）

## 任务概述

系统分析 PPS 和 Y 序列记号系统，建立两者之间准确的映射对应关系表。

## 关键洞察（来自 Prompt.md L49-84）

### SSS 记号系统的启示
SSS 展示了序数构造的基本模式：
- `SSS(0,1) = ω` - 第一个极限序数
- `SSS(0,1,0,1) = ω²` - 乘以 ω 的规律
- `SSS(0,1,1) = ω^ω` - 指数规律

**坏根概念**：SSS 中以 "0,1" 结尾的序数几乎总会往前找到形如 "0,0" 的子串，并把其中的第二个 0 作为坏根。

### 标准表达式原则（Prompt.md L82-84）
> 标准表达式定义为可以通过极限表达式经有限次展开并取基本列前若干项的方式得到的表达式。我们只考虑标准表达式。

**分析原则**：
1. 遇到多个可能表达式都能展开出相同结果时，检查哪个是标准表达式
2. **不要过多跳步**
3. 当遇到"固定的重现模式"时，才可以"适度用规律"加速
4. 确保背后对应的展开过程一致，不能仅看表面数字

## 分析计划

### 阶段 1：理解基本列的极限结构

**目标**：从极限表达式开始，理解 PPS 和 Y 的基本列构造差异。

**步骤 1.1**：分析 PPS 基本列
- `pps(0) = (0)` → 极限 `(0,1)` → 展开为 `0,0,0...`
- `pps(0,0) = (0,1)` → 极限 `(0,1,2)` → 展开为 `0,1,0,1...` ？
- 需要验证基本列的展开行为

**步骤 1.2**：分析 Y 基本列
- `y(1) = (1)` → 极限 `(1,n)` → 展开为 `1,1,1...`
- `y(1,1) = (1,2)` → 极限 `(1,2,3)` → 展开为 `1,2,1,2...` ？

**步骤 1.3**：比较两者极限结构
- PPS 极限：`0,1,2,3...n` → 对应什么 Y？
- Y 极限：`1,2,3,4...n` → 对应什么 PPS？

### 阶段 2：运行程序验证基本列

**工具**：`Program/seqtool.exe`

**验证案例**（按 README 的转换公式）：
```
1. pps(0)       → y(1)
2. pps(0,0)     → y(1,1) ?
3. pps(0,0,0)   → y(1,1,1) ?
```

### 阶段 3：验证递推公式

根据 README：
```
pps_to_y(pps(A, 0)) = y(pps_to_y(A), 1)
```

**验证步骤**：
1. 假设 `pps_to_y(pps(0)) = y(1)` ✓ 已确认
2. 验证 `pps_to_y(pps(0,0)) = y(pps_to_y(pps(0)), 1) = y(y(1), 1) = y(y(1), 1)`
   - 但 `y(y(1), 1)` 是什么？这需要展开理解
3. 继续递推验证

### 阶段 4：深入分析展开差异

**关键问题**：为什么 `pps(0,1)` 和 `y(1,2)` 展开完全不同？

根据 SSS 的坏根概念，可能是：
- PPS 和 Y 有不同的"坏根"定义
- 展开规则本质上不同

**需要验证**：
1. 坏根在 PPS 中的位置
2. 坏根在 Y 中的位置
3. 两者的坏根规则是否不同
