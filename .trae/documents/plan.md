# TraceMark AI 项目工作计划

## 已知信息

根据 `README.md` 和 `Prompt.md` 的内容，本项目是一个 **TraceMark AI（AI 分析记号）** 项目，核心目标是记录 AI 在分析过程中产生的逻辑记号、决策痕迹与数据快照。

### 核心文件结构

| 文件路径 | 职责 |
| :--- | :--- |
| `MEMORY.md` | 记忆文档，存放长期积累的背景信息和已完成决策。**只追加，不覆盖** |
| `ANALYSIS.md` | 分析表，存放当前的结构化分析、待办清单或数据推理过程 |
| `programs/` | 程序目录，存放执行器脚本 |
| `README.md` | 总览日志，**永不覆盖，只做追加** |

### 核心工作流程

1. **读取记号**：从 `MEMORY.md` 加载历史分析记号
2. **执行分析**：在 `ANALYSIS.md` 中更新当前的分析表
3. **运行程序**：调用 `programs/` 中的脚本进行数据处理
4. **沉淀记录**：将结果作为新的"记号"追加到 `README.md` 底部
