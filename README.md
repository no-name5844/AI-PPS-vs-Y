## PPS 记号系统定义
### 比较
$ A=(a_1,a_2,...,a_n) , B=(b_1,b_2,...,b_m)$ :
- 若所有项都相等，则$A=B$。
- 若他们分别由（0,1,2,...n）和（0,1,2,...,m）经有限次展开并取基本列前若干项的方式得到的表达式，且n>m 则，$A>B$。
- 若在某一次的展开过程中，分别为$ C[i]$ 和 $ C[j]$且$i>j$，则，$A>B$。
- 若 $ B < A $ ，则，$A>B$。
- 以上仅当A，B都是标准表达式时成立。
#### 标准表达式
- 标准表达式定义为可以通过极限表达式（0,1,2,3....n）经有限次展开并取基本列前若干项的方式得到的表达式。
### 程序规则
- 所有元素必须 ≥ 0
- 最后一个元素决定展开行为

2. **非极限情况**：逐项展开完全不等，简单+1映射是错误的

## 分析日志（2026-06-06）

### 重要发现

**MEMORY.md 中之前的记录存在错误！**

经使用 seqtool.exe 程序验证：

1. **y(1,1) 不是极限序数**
   - 程序运行 `y(1,1)` 展开时触发断言错误
   - 错误信息：`Assertion failed: !_isSuccessor()`
   - 结论：y(1,1) 是**后继序数**，不是之前认为的 ω
   - 同样 y(1,1,1)、y(1,1,1,1) 等也都是后继序数

2. **PPS 和 Y 的展开模式完全不同**
   - `pps(0,1)` → 全 0
   - `y(1,2)` → 全 1
   - `y(1,3)` → 2的幂 (1,2,4,8,16,32,64,128...)
   - `pps(0,1,1)` → 交替 0 和奇数 (0,1,0,3,0,5,0,7...)

3. **README 中的递推公式存在问题**
   - 公式1：`pps_to_y(pps(0)) = y(1)` ✓
   - 公式2：`pps_to_y(pps(A, 0)) = y(pps_to_y(A), 1)` - 当 A=(0) 时有问题
     - 计算：`pps_to_y(pps(0,0)) = y(pps_to_y(pps(0)), 1) = y(y(1), 1)`
     - 但 y(1) = ω，y(ω, 1) 不是合法的 Y 表达式

### 下午更新

1. **Y 序列中以 1 结尾的表达式都是后继序数**：
   - y(1,1) → 断言错误
   - y(1,1,1) → 断言错误
   - y(1,2,1) → 断言错误

2. **pps(0,1,0,1) 的展开**：
   - 结果：0,1,0,0,4,0,0,7,0,0,10,0,0,13...
   - 模式：开头 0,1,0,0，然后每3项循环（0, X, 0）

3. **PPS 和 Y 的展开模式比较**：
   | 情况 | PPS | Y |
   | :--- | :--- | :--- |
   | 基本列极限 | 全0 | 全1 |
   | 包含坏根 | 交替0和奇数 | 交替1,2 |
   | 高阶 | 0,1,0,0后每3项递增 | 2的幂 |

### 结论

1. **简单+1映射假设已证伪**：PPS 和 Y 的展开模式完全不同
2. **Y 序列的极限定义与 SSS/PPS 不同**：Y 中以 1 结尾的是后继序数
3. **需要重新审视 PPS 和 Y 的对应关系**：不能假设 y(1,1) = pps(0,0) = ω
